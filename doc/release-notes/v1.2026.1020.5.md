修复在非中文系统区域的电脑上，安装时创建快捷方式失败的问题。

**修复**

- 安装时报 `Unable to save shortcut ... YMacType ??.lnk`：之前用 Windows 脚本组件创建快捷方式，它会把文件名按系统 ANSI 代码页转换，系统区域不是中文时“设置”两个字变成 `??`，路径无效，安装在最后一步中断。现在改用 Unicode 的系统快捷方式接口，开始菜单快捷方式和应用启动器生成的桌面快捷方式都不再受系统区域影响。
- 上一次中断的安装不会留下问题：重新双击 `YMacType.Settings.exe` 安装即可，已复制的文件会先备份再替换。
