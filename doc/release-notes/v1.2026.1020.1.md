修复字体替换不生效和一类乱码问题，重做设置面板。

**修复**

- 配置文件编码：核心只认带 BOM 的 UTF-8 或 UTF-16 配置，无 BOM 的文件会被按系统 ANSI 代码页（中文系统即 GBK）读取，配置里的中文字体名会变成乱码、规则失效。默认配置改为带 BOM，设置面板保存时也会写 BOM，MacType.ini 保持 UTF-16；读取旧的 GBK 配置时也能正确识别；概览页可以一键修复已安装的旧配置。
- 替换字体缺失：`[FontSubstitutes]` 的目标现在可以写成候选链（`PingFang SC|Source Han Sans SC|Noto Sans SC|…`），按顺序使用第一个已安装的字体。以前目标字体没装时整条规则会被静默丢掉，现在会在日志里写警告（code=700），并在每个进程里记录生效规则数（code=701）。
- DirectWrite 字体替换在新字体创建失败时，会把已经释放的字体对象交还给程序，可能导致程序崩溃。现在只在新字体创建成功后才替换。
- 默认配置的 `[Exclude]` 段原本填的是进程名，这一段只认字体名，所以这些条目一直不起作用。现已清理，设置面板改放到 `[UnloadDll]`，并去掉了重复条目。

**设置面板**

- 新的左侧导航布局，跟随系统浅色/深色主题，标题栏也会同步变色。
- 概览页：服务状态、替换字体是否已安装、配置编码、已加载进程数、最近诊断和系统代码页一页看完，有问题的项目带修复按钮。
- 字体页：可以编辑替换字体链（排序、增删），用整条链渲染样张，并列出可以免费使用的中文字体及下载页面。
- 渲染页：新增“macOS 风格 / 均衡 / 清晰锐利”三个预设。
- 已生效应用页：可以直接把选中的程序设为“完全不处理”或“只渲染”。
- 新增乱码排查页：区分缺字、编码错误和字形错位三种情况；可以一键暂停某个程序做对比、再一键恢复；显示系统代码页和 UTF-8 Beta 开关状态；列出最近 24 小时的警告和错误，并附中文说明。
- 系统界面字体页按新样式重做，预览改成一个仿真的传统窗口。

**构建**

- 新增 GitHub Actions 工作流：在 Windows 上编译固定版本的 FreeType、IniParser、wow64ext 和 Detours，再编译 x86/x64 核心、加载器和设置面板。推送 `v*` 标签时会自动打包并发布 release。
